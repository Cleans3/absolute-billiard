# Bar room PBR textures (Poly Haven, CC0)

Written by `src/tools/make_textures.py`: 1k JPG downloads resized to 512/1024, albedo desaturated and normalised to a fixed mean luminance
so a BarSkin colour can tint it (see the script header). License: CC0 1.0, see LICENSE.txt.

- `floor/` = Poly Haven `dark_wooden_planks` by Amal Kumar, https://polyhaven.com/a/dark_wooden_planks (real-world tile [2000, 2000] mm)
- `wall/` = Poly Haven `red_brick_03` by Rob Tuytel, https://polyhaven.com/a/red_brick_03 (real-world tile [1000, 1000] mm)
- `wainscot/` = Poly Haven `wooden_panels` by Dimitrios Savva, https://polyhaven.com/a/wooden_panels (real-world tile [2099.9999046325684, 2099.9999046325684] mm)
- `ceiling/` = Poly Haven `ceiling_interior` by Dimitrios Savva, https://polyhaven.com/a/ceiling_interior (real-world tile [2000, 2000] mm)
- `wood/` = Poly Haven `dark_wood` by Dario Barresi, Dimitrios Savva, Rico Cilliers, https://polyhaven.com/a/dark_wood (real-world tile [2000, 2000] mm)
- `seat/` = Poly Haven `brown_leather` by Rob Tuytel, https://polyhaven.com/a/brown_leather (real-world tile [400.0000059604645, 400.00003576278687] mm)
- `metal/` = Poly Haven `metal_plate_02` by Rob Tuytel, https://polyhaven.com/a/metal_plate_02 (real-world tile [2000, 2000] mm)
- `felt/` = Poly Haven `velour_velvet` by colormass, Rico Cilliers, https://polyhaven.com/a/velour_velvet (real-world tile [284.22817052147235, 273.499995470047] mm)
